# Recreated visual identity — approved and locked

**Game name:** Recreated

**Tagline:** The world remembers. Nothing stays the same.

## Approved art direction

- Original cinematic title treatment: mystical purple sky, deep near-black shadows, glowing antique-gold broken halo/ring, and atmospheric fantasy tower.
- UI: dark violet and near-black surfaces, warm gold accents, parchment highlights, restrained serif headlines, crisp readable controls.
- Preserve the original approved interface icon sheet for Combat, Inventory, Ledger, The Author, The Weave, Loomhouse, The Mire, Settings, Save, and Rollback.
- Game camera and world: 2D/2.5D top-down/isometric action roguelite. Keep a distinct identity from Fate's Passage.
- **Do not** reuse the rejected third-person MMORPG gameplay mockup.

## Engineering acceptance criteria

1. All new UI and assets must match the established palette and visual language.
2. The offline HTML build must embed the approved images and function without network access.
3. Verify the logo and icons render at desktop and mobile sizes; preserve aspect ratio.
4. Changes to branding require explicit approval; never silently swap assets.

## Current integration status

The approved artwork is embedded in the local playable HTML builds through v1.1. The full playable HTML and artwork have not yet been imported into this GitHub repository. Do not claim that the repository hosts the game until that import is verified.
