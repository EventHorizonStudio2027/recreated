# Recreated — Unity 6 2.5D migration

This Unity project lives alongside, not in place of, the original offline browser game in the repository root. The existing `index.html`, JavaScript engine, and browser tests remain authoritative references during migration.

## Open
1. In Unity Hub, choose **Add project from disk** and select the **`unity`** directory.
2. Install/open with **Unity 6 6000.0.43f1** (or compatible Unity 6 editor). Package Manager will resolve URP.
3. In Unity choose **Recreated > Open Prototype Scene**. If the scene is missing, this generates `Assets/Recreated/Scenes/Prototype.unity` automatically and adds it to Build Settings.
4. Press Play. Keyboard/mouse: WASD/arrows to move, mouse to aim, left-click/Space to attack, Shift to dodge, Q for Echo Pulse. Gamepad: left stick to move, right stick to aim, south face button to attack, east face button to dodge, right shoulder to cast Echo Pulse. Gamepad support is source-implemented but Unity Play Mode verification remains pending.

## What is actually included
This repository contains the **Unity project source**, not a prebuilt Unity executable. The serialized `Prototype.unity` scene is generated by the Unity Editor; until you open the project and run the menu command, the scene file may not exist. The Unity Editor compilation and playtest have **not yet been verified**. If you see red Console errors, share the first error so it can be fixed at source.

## Automated scene generation (optional)
With Unity 6 installed, from the repository root run:
```bash
"/Applications/Unity/Hub/Editor/6000.0.43f1/Unity.app/Contents/MacOS/Unity" -batchmode -quit -projectPath "$PWD/unity" -executeMethod Recreated.Editor.PrototypeSceneBuilder.GenerateBatch -logFile "$PWD/unity-bootstrap.log"
```
Use the installed Unity Editor path if your version differs. Success prints `RECREATED_SCENE_READY` in the log and creates `unity/Assets/Recreated/Scenes/Prototype.unity`. Do not claim the scene works until Unity finishes importing and Play Mode runs without errors.

## Scope
Prototype foundation only: orthographic 2.5D camera, procedural primitive environment, player movement, simple melee and pulse, pursuing enemies, HUD, wave and health progression. Not yet feature-parity with the browser game. Source-only checks can run in GitHub Actions; actual Unity compilation and Play Mode testing still require Unity Editor/CI runner.

## Architecture
Runtime `Recreated.Runtime` assembly owns reusable gameplay systems. `Recreated.Editor` provides deterministic scene generation. No purchased assets or external SDK are required. Gameplay balance values are defined in `GameTuning` and can be moved into ScriptableObjects later.

## First-play verification and accessibility

Use the [first-play acceptance checklist](../docs/UNITY_FIRST_PLAY.md) before calling this prototype playable. In the Game view, verify both wide and narrow aspect ratios: health, chamber status, action hints, and victory/defeat text should remain readable against the arena. The current HUD includes a dark translucent backing panel, restrained gold/violet accents, a critical-health pulse and an animated completion underline; those **source-level visual improvements still require Editor verification**. Keep text contrast and space efficiency ahead of decorative effects.

**When blocked:** report the first red Console error (full stack trace and file/line), Unity version, and whether it occurred during import, scene generation, or Play Mode. Do not delete the browser game or overwrite unrelated Unity scenes as a troubleshooting shortcut.
